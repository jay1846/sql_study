# 01. Introduction & Environment Setup

## Topics covered
- SQL and databases: basic concepts
- Setting up a local development environment on macOS using Docker (SQL Server 2022) and VS Code (MSSQL extension)
- Creating a database by running an initialization script (init-sqlserver-mydatabase.sql),
  which creates `MyDatabase` with two tables: `customers` and `orders`, populated with sample data

## Scripts in this folder
| File | Description |
|---|---|
| `init-sqlserver-mydatabase.sql` | Creates `MyDatabase` and populates `customers` and `orders` tables with sample data |
